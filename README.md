# 《废卷》短片剧本

一部关于「自己给自己的标签」的 3 分 35 秒校园短片，全套前期物料。

## 一句话

一个把「我什么都能兜住」写在便签上的组长，用一道只准选一个的问卷题，把四个人都逼到了同一个墙角。

## 故事

四个女生做「大学生咖啡消费偏好调查」。开场按 MBTI 各挑各的活，四张便签全部是自己写的、自己贴的。
第 7 题是单选题，可 74 个人两个选项都勾了，问卷星只认第一个——于是 78% 这个数字，不是学生选的，是系统选的。
吵完一架，深夜有人去翻那 74 份废卷，第二天四个人各自撕掉自己那张便签。

## 关键设定

- 全片只出现一次 MBTI 字母，就在四个人自报的那四句台词里
- 四张便签全部是自己填的、自己贴的——不是被分配
- 第 7 题是「单选题」，所以答案永远只有两个：这是全片的核心装置
- 结尾不给满分：老师仍然说「数据重做一遍」
